
In dieser Lerneinheit sehen wir uns den Kernel eines Unix-Systems genauer an. Sie erfahren, wie ein Kernel konfiguriert und gebaut wird, wie dynamisch ladbare Kernel-Module funktionieren, und wie ein System Call im Kernel abgearbeitet wird. Weiterhin werden Sie dem für Lehrzwecke entwickelten minimalen Unix-Kernel xv6 beispielhaft einfache Funktionen und System Calls selbst implementieren.

Im Rahmen dieses Moduls können wir nur wenige punktuelle Einblicke in das "Innenleben" eines Unix-Kernels geben. Kernel-Programmierung ist ein komplexes Thema, das nur relativ wenige Spezialisten beherrschen.

# 1 Zusammenfassung

- Die meisten Unix-Systeme haben einen monolithischen Kernel, der alle Kernel-Funktionen in einem zusammenhängenden ausführbaren Programm enthält.
- Der Kernel wird vor dem Bauen durch Konfiguration an die jeweilige Hardware und den Einsatzzweck angepasst: Über Konfigurationsdateien werden Features ausgewählt und Parameter gesetzt.
- Ein Kernel-Modul ist eine als separate Binärdatei verteilte und zur Laufzeit dynamisch ladbare Kernel-Komponente. Hardware-Treiber und spezielle Dateisystemtypen werden oft als Module realisiert.
- Beim Starten eines Linux-Kernels können diesem Kommandozeilen-Parameter übergeben werden. Diese _kernel command line_ wird insbesondere zur Steuerung des Boot-Vorgangs verwendet.
- Manche Kernel-Parameter können zur Laufzeit modifiziert werden, z.B. für Speicherverwaltung, Netzwerk-Stack und Dateisystem. In Linux greift man über `/proc/sys` und das Kommando `sysctl` darauf zu.
- Ein System Call ist eine standardisierte Schnittstelle, über die Anwendungsprogramme Dienste des Kernels aufrufen können. Moderne Unix-Systeme kennen über 300 System Calls.
- Beim Aufruf eines System Calls wird mit einer Trap-Instruktion kontrolliert in den _kernel mode_ gewechselt. Dabei werden die System Call Nummer und evtl. Parameter über Register und/oder den Stack übergeben.
- Anwendungsprogramme rufen System Calls meistens nicht direkt per Trap-Instruktion auf, sondern verwenden dafür Funktionen der C-Standardbibliothek, die eine portable Schnittstelle bieten.
- xv6 ist eine am MIT für Lehrzwecke entwickelte minimale Reimplementierung des klassischen Unix V6-Kernels in modernem C.
